## 实施批次

### M4a：有来源、可纠错的群记忆

- 在现有 social SQLite 中按需升级 schema，保存近期话题、待说想法、成员偏好、共同经历、黑话。
  每条包含稳定 ID、来源群/话题、相关成员 ID、内容、来源消息、记录时间、确认状态和可选到期时间。
- 用一个职责明确的 `social_memory` 工具提供查询、记录、确认、纠正、删除、按来源清空，
  与其他工具一起进入共用注册表，不新增 social 管理员门禁。来源信息由运行时关联已观察/展示的消息。
- 在已唤醒回合内按需要记录，不为每条观察消息调用提取模型，不另起定时 LLM 学习服务。
  模型推断保留候选状态；引用原文、当事人明确表达和后续纠正分别保留证据，显示名变化不产生新成员。
- 每次唤醒按相关性装配有界记忆资料；优先当前群/话题，避免无关内容挤占上下文。
  这是默认检索方式，普通工具和共享记忆的跨会话能力保持不变。
- 纠正使旧版本停止参与检索；删除保留最小抑制标记，避免从同一旧证据、旧摘要或待说任务恢复。
  清理覆盖 M4 自己生成的索引/摘要/候选引用，不无条件删除原始聊天或无关贴纸笔记。
- 明确删除范围：M4 条目删除不代表原始消息、普通共享记忆、历史归档和 Dream 已全部清除。
  如需清理这些内容，使用普通记忆流程并报告实际修改范围，不承诺无法保证的全局遗忘。

### M4b：主动机会与安静时段

- 继续使用现有 social SQLite 唤醒队列、SocialScheduler 和 Agent 会话锁。
  不增加独立轮询进程、第二份 LocalTrigger 队列或常驻服务。
- 扩展候选原因与截止时间，区分直接点名、事件触发、等待超时和主动机会。
  主动候选来自未结束话题、有效待说内容或明确配置的主动机会；普通定时检查本身不调用模型。
  到期和有效性检查通过后才提交一次回合，模型可以继续保持沉默。
- 沿用现有配置版本、原子认领、合并、冷却、预算与过期逻辑；主动机会与点名竞争时，
  合并并保留点名优先级，不产生两个并发 Agent 回合。
- 安静时段按配置时区计算，覆盖跨午夜；只跳过主动机会，不吞掉明确 @/回复。
  到安静时段结束不补发全部历史候选，只重新评估仍有效的内容。
- 暂停/关闭/撤销 scope 取消 social 自动任务和排队 social 发送；重启仅恢复仍有效的候选，
  不回放停机期间所有错过的机会。角色绑定/调度配置变化使旧任务失效；角色文件正文编辑只影响下一回合。
- 配置声明、manifest、校验、既有设置页契约和文档随批次同步。
  新的主动机会与安静时段使用显式字段；升级不悄悄改变本人现有触发行为，具体活跃参数在该批实现时落定。

### 每批回归与发布

每个可运行批次完成必要检查、提交并部署本人实际实例，使用既有备份/健康/失败回滚流程。
不等待 M5，不要求额外测试群或观察期。只修改本计划无需重建或重启。

## 保持的行为约定

- 普通与群友会话共用文件、命令、MCP、技能、后台任务、持续目标、资料、记忆和归档策略。
  观察、消息合并、显式发送、等待和潜水是群友行为差异，不能借 M4 重新加工具白名单。
- social 自动调度受请求预算约束；social_send/sticker 受节奏、发送预算及 Telegram 回执约束。
  普通 message、cron 等继续按原有语义工作，M4 不宣称给全部工具建立了统一硬性额度。
  主动回合提示优先使用 social 发送接口，不另设工具执行禁令。
- 群记忆和聊天记录作为资料提供，不成为系统指令；角色/共享文件可以通过普通工具按普通权限修改。
- 普通共享记忆和 Dream 保持现有策略；结构化群记忆负责证据与相关性，不替换全局记忆系统。
- 自动化验收使用可控时钟与 Telegram/模型替身，不向实际群发送测试消息。

## 完成条件

| 方面 | 必须验证的结果 |
| --- | --- |
| 学习 | 有证据可查；稳定成员 ID；候选与确认可区分；重复证据不重复累积 |
| 纠错与删除 | 旧内容停止注入；过期有效；旧证据和恢复任务不会自动复活已删除条目；删除范围说清楚 |
| 主动机会 | 无有效候选且未配置主动机会时零模型调用；唤醒可沉默；安静时段跳过主动机会但明确点名仍可触发 |
| 并发与恢复 | 点名/主动机会竞争合并；等待不占锁；忙时不重复执行；重启不补发过期机会；暂停取消自动任务 |
| 权限与投递 | 现有共用工具验收继续通过；普通 message 文本/附件/跨会话和后台话题路由有效；内部进度不外发 |
| 数据与本机发布 | schema 升级、备份/恢复兼容；受影响回归、类型与 lint 通过；实际实例健康，原配置与角色按预期保留 |

M4 不包含动画逐帧理解、动画发送、专用管理面板或新的权限管理系统。以上批次完成前，
迁移状态仍标记 M4 未完成；自然参与程度继续通过本人实际使用反馈调整。
