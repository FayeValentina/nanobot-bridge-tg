# 2026-11-01 审查修复：第一批

用户要求后续只以 build 成功、服务能启动为验收；本批不运行测试套件、lint/typecheck 或额外业务验证。

## 已实施

- 为普通文件工具和本地附件路径加入运行时配置及标准 OAuth 目录保护，解析符号链接后再检查。
- 新增 Linux Landlock exec 后端，使用 ABI 3+ 约束文件读写、截断和跨目录移动；支持时额外约束设备 ioctl、跨域信号和抽象 Unix socket。网络保留。隔离失败终止启动，禁止静默降级。
- 本机发布在原备份完成后启用共用工作区边界和 Landlock；角色目录保留读写，归档/实时源码保留只读。其他 bots、跨群投递、主动频率和社交预算不改。
- 独立 dispatch/background/子代理任务从空 Context 启动；子代理工作区和来源显式传递。工具执行任务和文件工作线程仍保留其必要的当前回合上下文。
- 合并恢复阶段的重复 session 保存；保留用户输入提前落盘、子代理恢复基线和回合结束保存。
- 整份 apply_patch 事务移出事件循环；取消等待磁盘操作或回滚完成后才释放回合。转写的五处文件读取改为线程执行。
- 从 SocialStore 构造函数拆出建表和版本迁移，保留 schema 17 和迁移顺序，版本边界改为范围检查。
- release 默认直接构建、备份、部署并等待启动健康；完整测试和隔离冒烟保留为显式命令。
- 本机配置清除运行时已明确退役的顶层社交字段。

## 范围与后续

这不是所有架构问题已修复的声明。JSONL 常规保存仍采用原子全量替换；本批只合并恢复阶段可合并的写盘，未改写存储格式。AgentLoop、转录回放和网关等巨型模块仍需按职责分批拆分。标准路径以外的自定义凭据、显式配置的工具环境变量和管理员能力不由本批通用文件边界兜底。

构建、提交及实际部署结果以本机 release/state.json 和会话交付说明为准。
