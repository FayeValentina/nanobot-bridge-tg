# 普通闲聊更常一句一句发

2026-10-31，用户希望肥鱼更多分成多条短消息。原人设“一到三句口语”只约束总长度，
模型常把反应、补充和转折装进同一个气泡。现有 social_send.parts 已支持完整有序的 2–3 条消息，
这次只修改 [角色表达偏好](harness/groupmate.md)，无需新增发送通道或强制按标点拆句。

新偏好：普通闲聊有两个以上独立意思时优先拆成 2–3 个短气泡，每条通常一句；
一轮发完再等回应。只有一句的保持一条，不逐词发送、凑条数、复述或添无必要的追问，
代码、引用、步骤和连贯说明保持完整。一轮不必每个气泡都重复口头禅和表情。

现有运行实例 send_cooldown_seconds=2、max_sends_per_hour=60，沿用原节奏与限制；
每条气泡各占一个发送额度，分条仍使用一次 social_send.parts 完整提交。
人设前 600 字不变，V3 摘要、提示词和宽松参与标准均不改变。

## 验证

通过现有实际 V3→主模型→替身发送评估，输入没有要求分条，比较 group_meme、emotion_share、
peer_bot_call 三段普通闲聊。主模型仍是实例当前 deepseek-flash、temperature=0.1：

- 原人设：三例均为一个气泡。
- 新人设：三例均为两个独立气泡；各只调用一次 social_send，使用完整 parts，不同时传 text。
- 每条取得独立 sent 回执，未重复首段；不是在一条消息里插入换行。
- 现有人格装载与普通会话隔离回归 15 项通过，差异格式检查通过。

所有数据和发送为临时/替身，没有向真实群发送探针；六次合成回放不是长期分条比例的统计。
