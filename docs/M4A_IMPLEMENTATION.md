# M4a：有来源、可纠错的群记忆

2026-10-28 实现 M4 第一批：结构化群知识与工具，继续使用普通助手的工具和记忆权限。
主动机会与安静时段属于 M4b，本批不改变现有消息触发行为。阶段划分见 [M4 计划](M4_PLAN.md)。

## 存储与学习

现有 `telegram-social/social.sqlite3` 从 schema 3 升级为 4，新增 memories、memory_evidence、
memory_suppressions、memory_resets 四张表；沿用 SocialStore 的单连接所有者、事务与备份。
不新增数据库服务、模型提取循环或定时学习任务。观察消息本身仍不调用模型。

条目支持 topic（近期话题）、pending（待说想法）、preference（成员偏好）、experience（共同经历）、
slang（黑话），保存稳定 ID、来源群/话题、成员稳定 ID、内容、状态、依据、修订号、时间及可选到期时间。
每条最多 10 条来源证据，保存模型实际看到的文本片段、消息 ID、序号、作者 ID 和原消息时间；
不拿更长的原文或后续编辑后的版本冒充本回合看到的证据。来源消息清理后仍可查看已保存的证据。

模型在已唤醒回合内使用 `social_memory`，不增加每消息提取请求。记录和修改必须引用本回合已真正
提交给模型的消息；只被观察或刚由读取工具返回、还未送入模型的消息不能作为学习证据。
成员 ID 必须来自证据作者，不按显示名猜测。没有成员 ID 的条目可记录群级知识。

`basis=inference` 保持 candidate；direct 表示模型判断为直接陈述，corroborated 要求不同作者的证据，
这两种依据可标记 confirmed。依据是可审查的模型判断，不是程序对自然语言真伪的证明。
重复内容和相同成员/类别合并到同一 ID，来源消息去重；重复记录不会自动把推断升级为事实。

## 工具接口

`social_memory` 加入共用工具注册表，没有独立管理员授权或群友白名单。与其他 social 数据工具一样，
默认作用对象是当前有效群/话题；普通文件、MCP、跨会话及共享记忆工具保留普通能力。

| action | 用法 |
| --- | --- |
| list | 查询当前来源的条目；可用 query、kind、limit、offset、include_inactive；返回 next_offset |
| record | 提供 kind、content、message_ids；可指定 member_ids、basis 和 ttl_seconds |
| confirm | memory_id、message_ids 和 direct/corroborated 依据；追加独立证据、明确确认 |
| correct | memory_id、新 content 和新 message_ids；修订同一 ID，替换旧内容/证据，可附新依据 |
| delete | memory_id；删除内容、成员和证据，保留最小墓碑与抑制摘要 |
| clear | 清空当前来源的索引；记录已观察序号，旧消息不能在后续提取时重新填回 |

推断默认 7 天到期，topic 默认 7 天，pending 默认 1 天；其他已确认条目默认无固定到期时间。
可用 ttl_seconds 显式指定 1 秒至 365 天。重复记录不自动延长已有到期时间。
每来源最多 300 条有效条目，达到上限时返回明确错误，不静默覆盖旧知识。

## 自动检索与纠错

每回合按当前群/话题近期文本与发言者 ID 排序，装配最多 8 条、5000 字符以内的记忆资料。
资料是用户输入/工具结果层的数据，不写进系统人格。没有条目时不添加空资料；有删除/过期记录时，
可提供空的当前索引，明确旧快照不再代表有效知识。

资料通过现有回合 hook 临时附加到最新的待发送用户输入或工具结果，进入正常的上下文预算与压缩流程。
索引变化时续轮刷新；相同资料不在同一回合重复追加。请求完成或异常收尾时恢复原内容，
不把自动快照另存为会话历史；模型明确调用工具产生的结果仍按普通策略保留。
不改 AgentRunner 的压缩边界，不关闭普通记忆归档和 Dream。

纠正会保留 ID 并增加修订号，旧证据和旧内容进入抑制索引；删除会清除条目正文、成员和证据。
抑制记录只存来源消息 ID/规范化旧内容的 SHA-256 摘要，避免同一旧证据、旧工具结果或旧摘要直接复活条目。
过期条目退出检索，旧证据不能延长其生命；新的消息可支持重新学习已过期事实。
清空同时覆盖尚未被学成条目的旧观察消息。抑制记录不按普通消息保留窗口自动清除。

删除的范围是 **M4 索引**。原始群消息、普通共享记忆、会话工具结果、历史归档及 Dream 不随之全局清除；
如需清理这些内容，继续使用普通工具/记忆流程并报告实际范围。模型也不应宣称已“全局遗忘”。
本批没有额外衍生摘要库、成员画像服务或待说任务队列，因此不存在第二份 M4 提取/恢复副本。

## 验证与发布

纠错、删除/清空/过期不复活、事务回滚、数量/上下文限制、分页、重启和 schema 3→4。
Agent 集成通过真实工具执行路径验证按需学习、续轮删除刷新、下一次唤醒检索、快照不持久化与异常恢复。
旧 schema 1/2 升级验收随新版本更新，共用工具权限回归继续保留。

前端 96 文件共 1553 项，Ruff、WebUI lint/build 通过；修改模块严格类型 0 errors / 0 warnings。
部署版本和备份在发布完成后补记。
