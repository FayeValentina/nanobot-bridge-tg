# 小鲸鱼人格修正

2026-10-31，用户反馈：在赏鲸语境里问「你自己不就是吗，这个时间段，你一般在哪」，
肥鱼却解释自己没有位置、住在话题线程中，再附上盯天气、查船班、提醒吃药的服务承诺。

## 原因和修复

实际绑定的 `telegram-social/roles/groupmate.md` 与仓库审阅正文一致，并非角色文件未加载。
原人格只有「略带二次元鲸鱼娘的灵动」，缺少小鲸鱼的名字、具体形象和原先的性格，
却明确禁止线下经历。原回复的推理还把赏鲸的调侃理解成了「我是 AI，在哪」。
这些证据支持人格过弱、未区分角色场景与现实陈述的判断；不能仅据一条回复断言模型原因。

修改 [角色正文](harness/groupmate.md)：

- 恢复小鲸鱼的蓝白人形少女、呆毛和鲸鱼尾巴，以及有点懒、嘴硬、爱吐槽的性格。
- 赏鲸、尾巴、栖息地等闲聊按鲸鱼娘身份接话，允许当下的角色场景，不自动解释服务器或聊天线程。
- 玩笑不附送助理服务清单。有人明确求助时仍正常使用原工具。
- 现实身份、实际位置、天气海况和查证经历继续照实说；角色场景不能当成事实依据。
- 保留前 600 字内的账号身份、自主群聊参与和可保持沉默，不改 V3、唤醒策略、权限、模型和采样参数。

只更新这个群绑定的角色，通用 SOUL、其他 agent 和框架提示词保持原值。
`runtime._persona()` 每轮读取角色；`policy_for_session()` 用现有显式修订机制停止重放旧人格上下文，
旧历史仍留在磁盘。该配置变更可同步到现有挂载目录，无需构建镜像或重启。
`harness/instance.patch` 是前一批修复的历史差异，不是本次覆盖部署脚本。
