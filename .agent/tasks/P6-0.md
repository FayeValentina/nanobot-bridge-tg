## 背景

- **P0-1**：`TelegramSocialRuntime`（`nanobot/channels/telegram/social/runtime.py`，当前 960 行）是 god class；
  `JudgeCoordinator`、`SocialStickers`、`ExpressionLearner`、`JargonLearner`、`ContextSelector`、`_SocialExposureHook` 等持有 runtime 反向引用并访问其私有成员。
  目标（§4）：runtime 是 < 300 行的薄 facade；组件只接收窄依赖（store 仓储、配置访问器、绑定解析器），不再接收 runtime；
  拆出 `hook.py`、`delivery.py`、`waiting.py` 等（§4 目标结构）。
- **P2-3**：`nanobot/cli/gateway_runtime.py` 中 social 的装配（构造 runtime、judge provider、注册工具和 hook、热重载路径）

- **P2-1**：`nanobot/agent/tools/telegram_social.py` 一个类按名字分发 12 个工具 → 一个工具一个类，共享 `_SocialTool` 基类（只负责取 ctx、捕获异常、JSON 编码）。
